# Frostfall: Son Ateş — Core Project Brief

This is the canonical direction for future website work.

## Brand
- Game: Frostfall: Son Ateş
- Google Play: https://play.google.com/store/apps/details?id=com.ardaedits.frostfall
- Instagram: https://www.instagram.com/frostfall.game/
- Visual identity: frozen world, deep navy/ice blue, furnace fire orange, cinematic contrast.

## Website direction
- Premium dark-cinematic game website with multi-section / multi-page layout.
- Strong 3D depth, layered transitions, scroll reveals, parallax and animated cards.
- Responsive for desktop PC and Android phones/tablets.
- Touch-first mobile interactions; no hover-only essential controls.
- Respect reduced-motion settings and avoid heavy effects on mobile.
- Keep the supplied game screenshots, artwork, videos, logo and Google Play destination central.

## Languages
Language selector currently includes: English, Turkish, Greek, German, French, Spanish, Portuguese, Italian, Russian, Arabic, Chinese (Simplified) and Japanese.
The navigation and key hero/CTA content have localized strings for these markets. Any untranslated long-form copy falls back to English and should be professionally translated before claiming complete localization for every page.

## Android
- PWA manifest and service worker included.
- Publish over HTTPS to enable install prompt / Add to Home Screen support.
- Large videos are not cached by the service worker to reduce mobile storage and data use.

## Delivery requirements
- Keep all six pages and assets in their existing relative paths.
- Test on desktop Chromium and real Android Chrome.
- Check language switching, RTL Arabic layout, navigation, video playback and reduced-motion mode.
